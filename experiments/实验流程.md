# SEESM 实验流程记录

本文档记录当前语义安全余量（SEESM）论文实验的目的、步骤、运行代码、输出文件和当前进展。实验安全函数统一为：

```text
h_SEE = ||p_rel + tau v_rel|| - R_obs - R_robot - beta_i
```

固定安全距离 baseline 不额外加入 `R_safe`，而是写成 `beta_i = d_safe`。

## 1. 实验总目的

本论文实验要证明三件事：

1. 语义类别会改变安全余量：例如 `child_like` 应比 `adult`、`box` 保持更大的安全距离。
2. 上下文会调制安全余量：同一类别在静止、同向、横穿、迎面接近等状态下应有不同 `beta_i`。
3. Safety Guard 能保证语义余量不破坏 MPC-SECBF 可行性：当 `beta_hat` 过大时，应被投影、回退或置零。

当前执行顺序：

1. Phase 5：先打通日志链路和 CSV 字段检查。
2. Phase 6.1：做 Exp2 类别感知实验。
3. Phase 6.2：做 Exp3 上下文调制实验。
4. Phase 6.3：做 Exp4 Safety Guard 临界实验。
5. Phase 7：做主结果、实时性和小规模实车展示。

## 4. Exp2 类别感知实验

### 目的

Exp2 用来证明 `beta_i` 不是固定常数，而是会根据语义类别变化。固定几何和运动方式，只改变类别：

```text
box / adult / child_like / cyclist
```

期望趋势：

```text
beta(child_like) > beta(cyclist) > beta(adult) > beta(box)
```

在足够多 seed 的均值上，期望安全距离也呈现：

```text
D_min(child_like) > D_min(adult) > D_min(box)
```

### 场景设置

配置文件：

```text
swarm_test/config/secbf_scenarios.yaml
```

当前 Exp2 场景：

```text
Exp2_category_box
Exp2_category_adult
Exp2_category_child_like
Exp2_category_cyclist
```

场景参数：

```text
map: 12m x 6m
start: (0, 0)
goal: (12, 0)
obstacle_count: 1
obstacle_position: (6, 0)
motion_pattern: static_on_path
```

### 对比方法

`Fixed_margin`：

```text
所有类别 beta_bar = 0.4
mu = 1.0
```

`Category_only`：

```text
使用类别 beta_bar
mu = 1.0
```

`SEESM_Ours`：

```text
使用类别 beta_bar
使用上下文调制 mu(phi)
启用 Safety Guard
```

## 5. Exp3 上下文调制实验

### 目的

Exp3 固定语义类别为 `adult`，固定单障碍物几何半径，只改变运动上下文，验证 `beta_i` 不是静态查表，而是由：

```text
mu = 0.6 + 0.2 * f_head + 0.15 * TTC_norm + 0.1 * rho_norm
beta_hat = beta_bar(adult) * mu
```

进行动态调制。

期望趋势：

```text
beta_frontal_approaching > beta_crossing > beta_same_direction / beta_static
```

### 场景设置

配置文件：

```text
swarm_test/config/secbf_scenarios.yaml
```

当前 Exp3 场景：

```text
Exp3_context_static
Exp3_context_same_direction
Exp3_context_crossing
Exp3_context_frontal_approaching
```

统一参数：

```text
map: 12m x 6m
start: (0, 0)
goal: (12, 0)
obstacle_count: 1
semantic_class: adult
```

关键上下文设置：

```text
static: adult 静止在路径旁侧
same_direction: adult 在路径旁侧沿 +x 同向远离
crossing: adult 早期横穿机器人路径
frontal_approaching: adult 从前方沿 -x 接近机器人
```
